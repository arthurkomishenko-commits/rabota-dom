## DEC-0001 · Astro 7.2 + Tailwind 4 через `@tailwindcss/vite`
**Дата:** 07.08.2026 · **Фаза:** F0

**Что.** Стек поставлен в текущих мажорных версиях: Astro 7.2.0, Tailwind 4.3.3.
Tailwind подключён vite-плагином, отдельного PostCSS-конфига нет.

**Почему.** Это то, что ставит `astro add tailwind` в Astro 7 — идти против дефолта
интеграции значит чинить его при каждом обновлении.

**Следствие для работы.** Astro 7 новее базы знаний Claude Code, поэтому API сверяется
по типам установленного пакета (`node_modules/astro/dist/types/`), а не по памяти.
Это правило действует на всю дальнейшую работу.

**Альтернативы.** Astro 5 + Tailwind 3 (знакомее, но сознательно устаревший старт) — отброшено.

## DEC-0002 · Базовый путь `/rabota-dom`, единственный источник — `astro.config.mjs`
**Дата:** 07.08.2026 · **Фаза:** F0 · **Решение Артура**

**Что.** До покупки домена сайт живёт на GitHub Pages как project page:
`https://arthurkomishenko-commits.github.io/rabota-dom/`.
`site` и `base` заданы в `astro.config.mjs` и больше нигде не дублируются.
В коде используются `Astro.site` и `import.meta.env.BASE_URL`; ссылки между локалями
строятся через `astro:i18n` (`getRelativeLocaleUrl` / `getAbsoluteLocaleUrl`), которые
сами учитывают base.

**Почему.** Бриф §2 требует `/` = иврит без префикса. Под project page это `/rabota-dom/`.
Переезд на домен должен быть правкой двух строк, а не ревизией всех ссылок.

**Переезд на домен** (отдельным решением позже): `site: 'https://<домен>'`, `base: '/'`,
`public/CNAME`, проверить canonical и hreflang, запись сюда.

**Альтернативы.** (а) домен сразу — отложено Артуром;
(в) отдельный репозиторий `*.github.io` ради корня — отброшено: второй репозиторий
и разрыв связи с `rabota-dom`.

## DEC-0003 · Шрифт: сабсеты Rubik лежат в репозитории, пакет — только источник
**Дата:** 07.08.2026 · **Фаза:** F0

**Что.** Три файла (`hebrew`, `cyrillic`, `latin`, variable, normal) скопированы в
`src/styles/fonts/`. `@fontsource-variable/rubik` переведён в devDependencies и служит
источником обновлений через `npm run fonts:sync`. Italic и arabic не подключены.

**Почему.** Файл в `src/` проходит через Vite: получает хэш и base в URL автоматически,
и тот же самый путь используется в `<link rel="preload">` — preload гарантированно
совпадает с тем, что запросит `@font-face`. Через `node_modules` этой гарантии нет.

**Факт бюджета:** hebrew 9.1 КБ · cyrillic 14.8 КБ · latin 34.5 КБ, при лимите 40 КБ
(бриф §2). Проверяется в CI: `npm run check:budgets`.

**Альтернативы.** Импорт CSS напрямую из `@fontsource` — тянет лишние сабсеты и italic;
`public/fonts/` — потребовал бы вручную вписывать base в `url()`, то есть вторую копию
значения вопреки DEC-0002.

## DEC-0004 · Preload только сабсета языка страницы
**Дата:** 07.08.2026 · **Фаза:** F0

**Что.** На ивритской странице предзагружается только hebrew, на русской — cyrillic,
на английской — latin. Латиница (лого «RABOTA DOM») на he/ru догружается обычным путём
с `font-display: swap`.

**Почему.** Preload обоих сабсетов на иврите — это 43.6 КБ в критическом пути ради
одной строки лого. Лого не является LCP-элементом.

**Пересмотреть,** если после F3 замеры LHCI покажут сдвиг из-за подмены шрифта в шапке.

## DEC-0005 · Диммер фото — опт-ин классом, а не глобальным селектором
**Дата:** 07.08.2026 · **Фаза:** F0

**Что.** Правило из `docs/DESIGN_TOKENS.md` записано там как
`[data-theme="dark"] img:not(:hover)`, то есть применяется ко **всем** изображениям.
Реализовано иначе — утилитой `photo-dim`, которую нужно поставить осознанно.

**Почему.** И бриф §7, и шапка самого файла токенов требуют: filter только для статичных
фото ниже фолда, **в hero и сборках filter запрещён**. Глобальный селектор по `img`
нарушил бы это на первом же слое hero-сборки в F5 — и нашли бы это уже по просевшему FPS.
Значения токенов не менялись, изменён только способ применения.

**Статус.** Полная проработка внешнего вида — F1.

## DEC-0006 · Технические страницы F0 закрыты `noindex`
**Дата:** 07.08.2026 · **Фаза:** F0

**Что.** Все страницы фазы F0 отдают `<meta name="robots" content="noindex, nofollow">`.

**Почему.** Pages-сайт публичен с первого деплоя, а до Content Freeze он —
staging-проверка (протокол §9). Индексация технического каркаса испортит выдачу
ещё до запуска.

**Снять** в F8 вместе с фиксацией Content Freeze. Занесено в `docs/TODO.md`.

## DEC-0007 · Playwright для проверки гейтов
**Дата:** 07.08.2026 · **Фаза:** F0

**Что.** `playwright` (только chromium) добавлен в devDependencies.
`npm run gate:f0` снимает живой сайт на Pages и проверяет машинно: lang/dir, каскад темы,
переживание выбора после перезагрузки, отсутствие FOUC, зеркалирование логических
свойств, состав скачанных сабсетов. Скрины и JSON-отчёт — в `docs/evidence/f0/`.

**Почему.** Гейты требуют визуальных и поведенческих доказательств (протокол §7), а без
инструмента каждый такой гейт упирался бы в ожидание скринов от Артура. Дальше это же
понадобится в F1 (состояния компонентов ×2 темы ×2 направления) и в F5 (кадры сборок).
Playwright бесплатен и уже заложен в бриф §7 как фоллбек рендера OG — новая зависимость
не появляется, появляется раньше по времени.

**Важно.** Инструмент не отменяет протокол §6: проверка на **реальном устройстве**
(особенно iOS Safari, где dvh и dynamic viewport ведут себя иначе) остаётся за Артуром.
Headless Chromium — это не «проверено на телефоне».

**Альтернативы.** Расширение Claude in Chrome — не подключено в этой среде.
Ручные скрины Артура — блокируют каждый гейт ожиданием.

## ОТКРЫТО · Переключатель языков тянет все три сабсета шрифта
**Дата:** 07.08.2026 · **Фаза:** F0 → решать в F1/F3 · **нужно решение Артура**

**Факт (измерено, `npm run gate:f0`).** На каждой из трёх локалей браузер скачивает
**все три** сабсета: hebrew + cyrillic + latin ≈ 58.4 КБ. Ожидание манифеста
(«грузится только нужный сабсет») не выполняется.

**Причина — не ошибка настройки.** `unicode-range` работает верно: на странице физически
присутствуют все три письменности, потому что переключатель языков подписан на родных
языках («עברית · Русский · English»), а лого «RABOTA DOM» — латиницей.

**Развилка.**
(а) оставить родные названия — честнее и доступнее для пользователя, цена +14.8 КБ
на ивритской странице (кириллица ради одного слова «Русский»);
(б) подписать коды «HE · RU · EN» — латиница уже нужна для лого, ивритская страница
экономит cyrillic-сабсет; цена — менее очевидный переключатель;
(в) гибрид: коды в шапке, родные названия в подвале или в меню.

**Решение принимается в F1/F3 вместе с дизайном шапки.** Бюджет «≤40 КБ на сабсет»
(бриф §2) при любом варианте соблюдён — под вопросом суммарный вес страницы.
