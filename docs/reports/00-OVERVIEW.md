## Где проект сейчас

**Сайт собран и живёт.** 44 страницы на трёх языках, автодеплой на GitHub Pages
при каждом пуше. Всё, что не требует внешних данных, доделано.

Lighthouse в CI на всех страницах: **perf 99 · доступность 100 ·
best-practices 100 · LCP ≤1995 мс · CLS ≤0.031** — пороги брифа §10 выполнены.

**До запуска не хватает трёх вещей, и ни одна не про код:**
реальные паспорта работ, секреты Telegram и Cloudflare, подтверждённые ставки.
`npm run check:freeze` показывает это одной командой.

```
Content Freeze НЕ пройден:
✗ демо-паспорта в контенте (6 записей)
✗ полных паспортов 0, нужно 8
✗ rates.json.status = "draft", нужно "production"
```

Это не ошибка сборки — это состояние проекта, и оно правильное.

## Найденные дефекты

Десять записей в `docs/BUGS.md`. Три из них стоят упоминания здесь, потому что
все три были **невидимы для сборки**:

**BUG-0006 — две локали из трёх молча пропадали из коллекции.** Loader брал `id`
из поля `slug`, общего у трёх языков. Из шести записей жили две. Сборка зелёная,
схема довольна. Поймал снимок витрины, а не проверка — отсюда правило в кодекс:
отсутствие данных само по себе не производит ошибку.

**BUG-0009 — форма заявки была мертва целиком.** Компонент кнопки не пробрасывал
`data-`атрибуты, скрипт не находил собственную кнопку. В консоли тихо ровно до
момента, когда кто-то нажмёт.

**Lighthouse мерил страницу без стилей.** `staticDistDir` раздаёт сборку из
корня, а ресурсы ждут базовый путь. Первые цифры — perf 100, LCP 245 мс —
не значили ничего. Честный замер показал LCP 3753 мс, и это привело к трём
реальным оптимизациям.

## Решения

Двадцать записей в `docs/DECISIONS.md`. Ключевые:

- **DEC-0002** — адрес и базовый путь в одном месте; переезд на домен = правка
  двух строк.
- **DEC-0011** — витрины компонентов нет в production-сборке вовсе, плюс сторож
  по факту содержимого `dist`.
- **DEC-0012** — контраст: введён `--accent-text`, `--accent-wood` не тронут;
  опознание поля ввода повешено на «линию чертежа», а не на рамку.
- **DEC-0013** — сырьё контента одной папкой на объект, вне `src/assets`.
- **DEC-0014** — демо-контент виден и помечен; демо-отзыв **невозможно создать**,
  схема его отвергает.
- **DEC-0019** — OG рисует браузер: satori не прошёл визуальный тест иврита.
- **DEC-0020** — один признак публичного запуска на `noindex`, robots и sitemap.

## Как проверить всё одной командой

```bash
npm run check        # конвенции, границы, метки, бюджеты, фразы, контент,
                     # контраст, тесты Worker, самотест, типы
npm run build        # сборка + публичный контур
npm run polish:pages # 44 страницы × чек-лист доступности и отказов
npm run check:freeze # можно ли выпускать релиз (сейчас — нет, и это верно)
```
