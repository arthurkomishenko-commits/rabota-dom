Чего нет и что делать:
1. **Схематичные слои собственной генерации.** Настоящих ассетов нет (Q-03),
   но манифест 06 прямо разрешает подмену: рисуем слои сами в чертёжном языке
   (как `scripts/make-placeholders.mjs` рисует заглушки паспортов) и описываем
   их JSON-манифестом по готовой схеме.
2. **Загрузчик манифеста** в `src/data/` — единственный слой, которому можно
   знать, откуда берутся данные.
3. **`LayeredObject`** — рендер слоёв: `width`/`height` обязательны у каждого
   `<img>`, иначе поедет CLS.
4. **Hero-сборка v1** по режиссуре брифа §3, помеченная **черновой**.
5. **Ритм секций** и замер 60 fps при CPU ×4 (троттлинг есть только в Chromium).

**Начинать с мини-плана в манифесте** — работа затрагивает больше трёх файлов.

## 7. ЧЕГО НЕЛЬЗЯ ДЕЛАТЬ

Это не пожелания. Каждый пункт появился после конкретной поломки.

1. **Не ослаблять гейт, чтобы он прошёл.** Порог 1600 px, порог LCP 2000 мс,
   `check:freeze` — чинится код, а не порог. Если число выбрано неверно,
   это доказывается записью в DECISIONS с разбором, почему прежнее было
   ошибкой, а не неудобством (пример — DEC-0023).

2. **Не судить о результате по выводу — только по коду возврата.** Я на этом
   обжёгся: прогнал `npm run check`, отфильтровал вывод `grep`, не заметил
   отсутствия строки «0 errors» и уехал в CI со сломанной сборкой.
   ```bash
   npm run check > /tmp/c.log 2>&1; echo "код возврата = $?"
   ```

3. **Не сравнивать два состояния, не доказав, что они разные.** Первый A/B
   по LCP «показал, что разницы нет» — потому что сборка не прошла, и я
   сравнивал одну сборку с собой. Сверяйте хеш артефакта.

4. **Не брать в паспорт изображение неизвестного происхождения.** Два
   состояния кадра: фотография из папки Артура либо схема нашей генерации.
   Третьего — «файл, который выглядит подходящим» — не существует (BUG-0013).

5. **Содержимое не должно зависеть от выполнения скрипта.** Финальное
   состояние живёт в разметке; анимация только доводит. На этом ловились
   четыре раза: BUG-0010, BUG-0017, BUG-0019, BUG-0020.

6. **Проверка обязана мерить то, что заявляет.** Мои же проверки трижды
   показывали зелёное, глядя мимо: бюджет скриптов считал предыдущую сборку,
   потом не видел встроенных скриптов, потом не видел динамических импортов;
   `check:motion` смотрел страницу без JS — ровно там, где анимации нет.

7. **Не списывать расхождение движков на «особенность браузера».** Дважды
   Chromium прятал общий дефект — метриками шрифта и скоростью выполнения.

8. **Не публиковать чужие фотографии и людей без согласия.**

## 8. Как проверить всё одной командой

```bash
npm run check          # конвенции, границы, бюджеты, фразы, контент,
                       # мёртвый текст, контраст, тесты, самотест, типы
npm run build          # сборка + публичный контур + бюджет скриптов
npm run polish:pages   # 44 страницы × три движка × чек-лист  (~40 мин)
npm run scenarios      # сквозные пути × 3 языка × 2 темы     (~15 мин)
npm run check:motion   # анимации: содержимое не зависит от скрипта
npm run audit:integrity# ссылки, hreflang, canonical, sitemap
npm run check:freeze   # можно ли выпускать релиз (сейчас — нет, и это верно)
```

Долгие прогоны запускать в фоне и **дожидаться кода возврата**.
