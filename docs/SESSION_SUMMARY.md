  двух строк (DEC-0002).
- Токены обеих тем из `docs/DESIGN_TOKENS.md`, каскад темы без FOUC,
  выбор пользователя переживает перезагрузку.

- Три машинные проверки, падающие в CI: конвенции (`100vh`, физические left/right),
  бюджеты сабсетов, типы.
- CI зелёный, деплой автоматический, сайт живой.

### Что нашлось по ходу

1. **Переключатель языков тянет все три сабсета** (≈58 КБ на страницу вместо ~44).
   Не ошибка настройки: `unicode-range` работает верно, просто на странице реально
   присутствуют три письменности. Развилка описана в `docs/DECISIONS.md`
   («ОТКРЫТО · Переключатель языков») — решается в F1/F3 вместе с дизайном шапки.
2. **Диммер фото в `docs/DESIGN_TOKENS.md` записан как глобальный селектор по `img`**,
   что противоречит требованию «в hero и сборках filter запрещён» из того же файла
   и брифа §7. Реализовано опт-ин классом `photo-dim` (DEC-0005). Значения не менялись.
3. **Actions выдавали предупреждение о Node 20** — версии подняты до актуальных мажоров.
4. Первая версия проверки зеркалирования была написана неверно (сравнивала грань
   с нулём, а не стороны между собой) и дала шесть ложных провалов. Исправлена;
   вёрстка была корректной изначально. Записано в `docs/BUGS.md`.
