# F9 — подготовка Decap CMS (не включено)

Фаза F9 наступает **после стабилизации запуска** (бриф §9). Здесь только
подготовка: конфигурация полей и пошаговый план. Ничего не включено —
`/admin` остаётся заглушкой, сторонние скрипты не подключены.

## Что решено брифом и не обсуждается

- **v1 запускается без CMS.** Публикует Артур коммитом; Владимир передаёт
  материалы в Telegram — привычный ему канал.
- Авторизация — **готовый open-source OAuth-прокси** на Worker, не самописный.
  Своя реализация OAuth это ровно тот случай, где ошибка стоит доступа
  к репозиторию.
- GitHub-аккаунт Владимира — коллаборатор репозитория.
- Медиа оптимизируются Action'ом **после** коммита CMS: иначе репозиторий
  начнёт расти неоптимизированными файлами, что прямо запрещено гейтом F9.
- Ветки CMS: Zod — ошибка, LHCI — предупреждение, auto-merge при зелёной Zod.
- Поля строго типизированные, markdown по минимуму.

## Схема полей уже существует

`src/data/schemas/work.ts` — это и есть контракт CMS. Поля Decap описываются
по нему один в один, включая то, что легко потерять:

| Поле схемы | Тип в CMS | Почему именно так |
| --- | --- | --- |
| `title` | string, обязательное | Без него карточка резала описание (BUG-0007) |
| `type`, `material` | select по кодам | Коды не переводятся; подписи берёт сайт |
| `year`, `duration` | number + единица | Технические значения структурны (BUG-0005) |
| `metrics` | list, минимум 1 | Фейков быть не может, пустых метрик тоже |
| `photos` | list, минимум 3 | Cover обязателен, ≥1 кадр процесса |
| `coords` | number, шаг 0.001 | Больше трёх знаков — точный адрес клиента |
| `review.consent` | boolean, обязателен true | Без согласия отзыв не публикуется |
| `demo` | скрытое, всегда false | Демо создаёт только разработка |

**Ограничение шага координат в CMS обязательно.** Без него Владимир вставит
точку из Google Maps со всеми знаками, схема отвергнет запись, и он получит
непонятную ошибку вместо подсказки.

## План включения (когда дойдёт очередь)

1. Поднять OAuth-прокси на Worker (готовый, из списка рекомендованных Decap).
2. Добавить аккаунт Владимира коллаборатором.
3. Положить `public/admin/config.yml` по таблице выше.
4. Включить `/admin` вместо заглушки.
5. Action оптимизации медиа после коммитов CMS.
6. Правила веток: Zod = error, LHCI = warn, auto-merge при зелёной Zod.
7. **Гейт F9:** Владимир самостоятельно публикует тестовую работу с телефона;
   репозиторий не растёт неоптимизированными файлами.

## Чего здесь намеренно нет

Конфигурация CMS не написана до включения. Написанная заранее, она разойдётся
со схемой за те месяцы, что пролежит без дела, — и разойдётся молча. Таблица
выше описывает соответствие, а сам файл создаётся в момент включения,
сверяясь с актуальной схемой.
