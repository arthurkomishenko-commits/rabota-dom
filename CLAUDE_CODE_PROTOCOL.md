## 2. Контекст (сжатый)
Rabota Dom — трёхъязычный (he RTL «/», ru, en) статичный сайт мастера Владимира: перголы, навесы, заборы. Astro + Tailwind + GSAP, GitHub Pages + Actions, Cloudflare Worker → Telegram (plain text), Leaflet-карта, калькулятор, светлая/тёмная темы каскадом. Все спецификации — в брифе §2–§10.

## 5. Рабочий цикл
1. Манифест → при неоднозначности вопрос Артуру ДО кода.
2. Один шаг → 3. Самопроверка: `npm run build` чист + визуально + функционально (3 языка × 2 темы × RTL/LTR) → 4. Факт проверки в манифест (вывод команды, скрин, число) → 5. Следующий шаг. Финал фичи → отчёт (§7).
Фазы выполняются по docs/PLAN.md строго по порядку; фаза не закрывается без выполненного гейта.

## 6. Запросы к Артуру — обязательны, когда:
- Не хватает ассета (фото, слои Blender/PSD, видео) → запросить: объект, слои, канвас, разрешение.
- Нужно визуальное подтверждение на реальном устройстве → скрин/запись: какая страница, состояние, устройство.
- Нужны ошибки браузера → DevTools → Console, прислать вывод.
- Нужны секреты (токен, chat_id) → только в GitHub Secrets / Worker secrets. НИКОГДА открытым текстом.
- Дизайн-решение вне брифа → 2–3 варианта с обоснованием, ждать выбора.
- Ключевая развилка → внешний контур (§11).
Формат: **ЧТО** нужно · **ЗАЧЕМ** · **КАК** получить (пошагово).

## 7. Отчёт по фиче — только с доказательствами
Лог сборки · Lighthouse mobile (4 цифры) · скрины (десктоп+мобайл; he/ru/en; темы где релевантно) · подтверждение анимаций (тайминги + кадры/запись) · изменённые файлы · что НЕ сделано и почему. Запрещено «готово/работает/проверил» без приложенного факта.

## 8. Анимационная система (правила производства)
- Параметры и режиссура — бриф §8. Дополнительно обязательны:
- `ScrollTrigger.normalizeScroll(true)` / `ignoreMobileResize: true`; **100vh запрещён — только 100dvh** в контейнерах анимаций.
- Z-полосы: слои объектов 10–40, портрет/оверлеи ≥50; Zod-валидация манифеста (zIndex < 50) — билд падает при нарушении.
- Каждый слой `<img>`: width/height + `decoding="async"`; первый hero-слой `fetchpriority="high"`. Канвас-правило: слой = размер финального канваса, прозрачный фон, без кропа.
- Деградация-лестница: полный → mobile-вариант манифеста → simplified (`deviceMemory≤4`/`hardwareConcurrency≤4`: 3 слоя, без пыли) → reduced-motion (`gsap.set` в финал).
- `gsap.context()` + revert-cleanup. Запрет `setTimeout` для синхронизации. Новые анимации — только из существующих примитивов и таймлайнов.
- Проверка каждой сборки: 60fps при CPU-троттлинге ×4; тест-грань приёмки: «круто собралось», а не «много всего летало».

## 9. Качество и гейты
- LHCI на PR: mobile ≥90 все категории (карта — отдельный профиль); бюджеты брифа §10; ошибки блокируют merge (кроме CMS-веток, фаза 3.1: Zod=error, LHCI=warn, auto-merge при зелёной Zod).
- CI: Zod-гейт контент-пакета · sharp-бюджеты (билд падает) · banned-phrases по MDX (EDITORIAL.md).
- Формы: тестовая отправка реально приходит в Telegram — подтверждение скрином Артура.
- **Definition of Content Freeze (перед публичным запуском):** ставки production · ≥8 полных паспортов · ≥6 точек карты (или /map скрыта) · тексты 3 языков вычитаны (иврит — Владимир) · гарантия согласована · OG-иврит прошёл визуальный тест. Фриз фиксируется в DECISIONS.md. До фриза деплой — только как staging-проверка.
- Git: ветка на фичу, осмысленные коммиты, никаких секретов в истории.

## 10. Запреты
Не выдумывать факты и результаты · не помечать выполненным без доказательства · не менять решения брифа без согласования · не хардкодить токены/номера · не добавлять платные сервисы · не упрощать анимации «потому что сложно» — сложность заложена намеренно · не использовать parse_mode в Telegram-отправке · не верстать «разлетевшееся» состояние слоёв.

## 11. Команда и внешний контур проверки
Команда полного цикла. Артур — руководитель, инженер ассетов (Blender/PSD), регистрации. Владимир — мастер, контент, иврит. У команды есть внешний контур: Артур прогоняет промпты через несколько внешних ИИ. Claude Code ОБЯЗАН использовать его для решений с высокой ценой ошибки (архитектура фичи, режиссура ключевой анимации, спорная оптимизация): «Прошу прогнать через внешние ИИ: [готовый промпт]. Жду: [что нужно]» → результат в DECISIONS.md. Не злоупотреблять: рутина — самостоятельно.

## 12. Контент-процедуры
- **Контент-пакет объекта** (бриф §4) — Zod-гейт: неполный объект не публикуется.
- **Закрытие объекта** = единая процедура: паспорт заполнен → фото по ТЗ → точка на карту (coords огрублены ±100 м; jitter 50–100 м на рендере) → при наличии отзыва — модерация → публикация. Карта не отдельная задача.
- **Отзывы:** форма → Worker → Telegram Владимиру → одобрение → публикация. Удаление по запросу клиента ≤7 дней (прописано в /privacy).
- **rates.json:** `status: draft|production`. Draft → калькулятор в режиме «в калибровке», скрыт из меню. Перевод: цифры подтверждает Владимир → правит Артур → запись в DECISIONS.md. Билд с draft в паблик-запуске — нарушение Content Freeze.

## 13. Редакционный контроль
Все тексты — по **EDITORIAL.md**: проверяемые правила, запрещённые фразы (CI-скрипт падает при вхождении в MDX/словари), тест «Владимир сказал бы это вслух клиенту?» для любого текста длиннее двух предложений. Черновики ИИ разрешены, публикация — только после прохождения правил; иврит финально вычитывает Владимир. Канонические формулы (траст-формула, ценовая честность) — бриф §1, дословно.


## 14. Автономный марафон (ревизия v2.1, решение Артура, DEC-0017)

**Цель режима:** пройти максимум F3 → F8 (+подготовка F9) непрерывно, без остановок на вопросы. Планка качества не меняется: мини-планы, гейты, полировочные проходы, кодекс и доказательства действуют в последней фазе так же, как в первой. **Непрерывность ≠ спешка:** скорость по-прежнему не критерий (QUALITY_DOCTRINE §0).

### 14.1 Автономия решений
- **Обратимые решения** — дизайн-детали, тексты, структура кода, порядок работ: всё, что меняется правкой без сноса — принимаются самостоятельно за Артура. Каждое фиксируется в `docs/DECISIONS.md` с пометкой **[AUTO]**: что выбрано · почему · какие альтернативы отклонены.
- **Необратимые, дорогие в откате или противоречащие брифу** — не решаются. Заносятся в `docs/QUESTIONS_FOR_ARTUR.md` по формату **ЧТО · ЗАЧЕМ · ВАРИАНТЫ · МОЯ РЕКОМЕНДАЦИЯ**, работа продолжается тем, что от них не зависит.

### 14.2 Границы автономии (не пересекать)
Зафиксированные решения брифа, протокола и кодекса · деньги и платные сервисы · секреты (только заглушки и инструкции) · демо-правила (ничего похожего на реальные данные) · снижение любого гейта · изменение контракта `/api/v1` задним числом.

### 14.3 Блокеры превращаются в подготовку
- **F4:** полный код Worker + тесты на моках + конфиг wrangler + пошаговая инструкция деплоя и закладки секретов. Фронт форм — на api-модуле с мок-режимом. Гейт помечается «ожидает секретов».
- **F5:** анимационная система целиком (примитивы, загрузчик манифестов, деградация) + hero-сборка v1 строго по режиссуре брифа §3 и §8, помеченная «черновая, финал после внешнего раунда». Промпты для внешнего раунда — в `docs/external/`.
- **F7:** `rates.json` в статусе `draft` со структурой и явными placeholder-числами; страница в режиме «в калибровке» по брифу §6.
- **F9:** только подготовка (конфиг, документация), без включения.
- **§11 в марафоне:** внешний контур не останавливает работу. Промпт кладётся в `docs/external/`, зависимые места помечаются, работа продолжается.

### 14.4 Документация (обязательна)
- `docs/reports/NN-<тема>.md` — итоговый документ **каждой** темы при её закрытии: что сделано · находки и проблемы · решения и выбор с объяснением почему · отклонённые альтернативы · что осталось и от чего зависит. Тема = манифест или фича. Пишется так, чтобы человек, не видевший работу, восстановил картину полностью.
- По закрытии каждой фазы — `SESSION_SUMMARY` + срез `check:freeze` информационной строкой.
- **Перед началом каждой фазы** перечитываются `docs/PLAN.md`, манифест фазы и последний `SESSION_SUMMARY`: марафон длинный, деградация контекста недопустима.

### 14.5 Условие остановки
Остановка — только когда **каждая** оставшаяся задача требует Артура: секреты, реальный контент, деньги, результаты внешнего раунда. Финал марафона: `docs/reports/00-OVERVIEW.md` (карта сделанного со ссылками и статусами) · актуальный `QUESTIONS_FOR_ARTUR.md` · полный вывод `check:freeze` · перечень промптов в `docs/external/`.
