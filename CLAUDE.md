# CLAUDE.md — конвенции проекта Rabota Dom

Рабочий файл для Claude Code. Иерархия документов:
**PROJECT_BRIEF.md** (что решено) → **CLAUDE_CODE_PROTOCOL.md** (как работать) →
**EDITORIAL.md** (тексты) → **docs/PLAN.md** (фазы) → **docs/manifests/NN-*.md** (фича).
При конфликте: бриф главнее по решениям, протокол — по процессу.

Перед любой работой: прочитать протокол целиком. Без манифеста работу не начинать.

## Команды

| Команда | Что делает |
| --- | --- |
| `npm run dev` | дев-сервер |
| `npm run build` | конвенции + бюджеты + сборка (падает при нарушении) |
| `npm run check` | конвенции + бюджеты + типы, без сборки |
| `npm run check:conventions` | нет `100vh`, нет физических left/right в раскладке |
| `npm run check:budgets` | сабсеты шрифта ≤40 КБ, состав сабсетов зафиксирован |
| `npm run check:types` | `astro check` |
| `npm run fonts:sync` | пересобрать сабсеты Rubik из @fontsource после обновления |
| `npm run preview` | локальный просмотр `dist/` |

## Стек и версии

Astro 7.2 · Tailwind 4.3 (`@tailwindcss/vite`) · TypeScript strict · GSAP (F5) ·
Cloudflare Worker (F4) · Leaflet (F6). Node ≥22.12, в CI — 24.

## Конвенции кода

- **Только логические свойства.** `margin-inline-start`, `inset-inline-end`, `border-block-end`.
  Физические left/right ловит `check:conventions`. Осознанное исключение — комментарий
  `physical-ok` в той же строке.
- **`100vh` запрещён.** Только `100dvh`; утилиты `h-viewport` / `min-h-viewport`.
- **Направления анимаций — параметр, не хардкод.** Для RTL используется `rtlInvertX`,
  а не зеркальная копия таймлайна (бриф §2, §8).
- **Токены только из `docs/DESIGN_TOKENS.md`.** Значения перенесены в
  `src/styles/variables.css` дословно; менять без согласования нельзя (бриф §7).
  Новых цветов «на глаз» не заводить.
- **`site` и `base` живут только в `astro.config.mjs`.** В коде — `Astro.site` и
  `import.meta.env.BASE_URL`. Второй копии адреса быть не должно (DEC-0002).
- **Z-полосы:** слои объектов 10–40, портрет и оверлеи ≥50 (бриф §8). С F2 — Zod-валидация.
- **Изображения:** каждому `<img>` — `width`/`height` и `decoding="async"`;
  первому слою hero — `fetchpriority="high"`.
- **Фильтры на фото — только ниже фолда**, через класс `photo-dim`. В hero и сборках
  `filter` запрещён (бриф §7). Глобального селектора по `img` не заводить.
- `gsap.context()` + revert-cleanup; `setTimeout` для синхронизации запрещён.

## Definition of Done (одного шага)

1. `npm run build` чист — без ошибок и ворнингов.
2. Проверено функционально: 3 языка × 2 темы × RTL/LTR.
3. Факт проверки записан в манифест фазы: вывод команды, число или скрин.
   Без факта шаг не считается выполненным (протокол §5, §7, §10).
4. Изменения закоммичены осмысленным сообщением, секретов в истории нет.

«Готово», «работает», «проверил» без приложенного доказательства — запрещённые слова.

### BANNED_PHRASES

Каркас из EDITORIAL.md. CI-скрипт (F2) сканирует MDX и словари i18n и падает при вхождении.
Список пополняется здесь.

```js
export const BANNED_PHRASES = {
  ru: [
    'индивидуальный подход',
    'высокие стандарты',
    'идеальное решение',
    'в современном мире',
    'широкий спектр',
    'богатый опыт',
    'команда профессионалов',
    'динамично развивающаяся',
    'лучшее соотношение цена/качество',
    'гибкая система скидок',
    'качественно и недорого',
    'мы предлагаем вам',
    'дёшево',
    'дешево',
  ],
  en: [
    'tailored solutions',
    'high standards',
    'wide range of services',
    'team of professionals',
    'best price-quality ratio',
  ],
  he: [
    'פתרונות מותאמים אישית', // как штамп в тексте; в дескрипторе лого — допустимо
    'סטנדרטים גבוהים',
    'מגוון רחב של שירותים',
  ],
};
```

**Стоп-слова** («качественно», «профессионально», «надёжно», «современно», «лучший») —
не запрещены полностью, но не могут стоять как самостоятельное преимущество: только
рядом с цифрой, материалом или сроком. Проверяется вручную при вычитке.

